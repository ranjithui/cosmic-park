 IF YOU EVER NEED TO CHANGE THE DATABASE PASSWORD
------------------------------------------------------------

  1. Open an ADMIN terminal and run:
       "C:\Program Files\PostgreSQL\18\bin\psql.exe" -U postgres -h localhost -p 5432 -d postgres

       \q

  2. Update DATABASE_URL in  apps\api\.env  to match.

  3. Update this file.

  If the password contains any of  @ : / ? # % &  it must be
  percent-encoded inside the connection string. Sticking to
  letters and numbers avoids the problem entirely.
